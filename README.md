# 🌐 ENIAD Semantic Web & Knowledge Graph Ontologies

Knowledge engineering, ontology modeling, and semantic graph formalization developed for the **Gestion des Connaissances et des Ontologies** module (Semestre 8) at **ENIAD** (*École Nationale d'Intelligence Artificielle et du Digital*).

---

## 🎯 Architecture & Modeling
- **Ontology Web Language (OWL 2)**: Formal conceptual schemas representing digital libraries, bibliographic metadata, and relational ontologies.
- **RDF & SPARQL**: Resource Description Framework triples, semantic querying, and taxonomy hierarchies.
- **Protégé & XML Schema**: Class hierarchies, object/data properties, domain/range constraints, and XML catalog mapping (`catalog-v001.xml`).

## 📁 Repository Structure
- `Biblio.owl`: Bibliographic and publication schema.
- `ontologie1.owl` / `ontologie2.owl`: Core domain knowledge ontologies.
- `tp1_library.owl` / `tp1_library_cleaned.owl`: Institutional library ontology and cleaned ontology models.
- `TP1_Library_Report.pdf`: Comprehensive theoretical and empirical report on ontology engineering.
